Checkout still imports Auth

Seven packages on one rail. Neighbour imports stay low. Checkout sits at the far end and still reaches back to Auth — five seats, the tallest arc, the coupling that will hurt a split.

The skip is the story

Five seats back to Auth

Checkout's other edges are neighbours. The coral arc is the one that is not: it clears Catalog, Search, Billing and Ledger to land on Auth. A ranked dependency graph would bury that skip inside the hairball. Height makes it the first thing the eye hits.

Height is the seat count

One pitch, rising semicircles

Every node sits 140 px from the next. A one-seat import is a semicircle of radius 70; a five-seat skip is radius 350. The same count always draws the same height, so a neighbour cannot wear a skip's arc.

The rail is not a scale

Seats, not values

Left-to-right is package order, not importance and not time. Nothing is moved along the rail to open up space — crowding on the line would mean two packages occupy one seat, which this figure does not allow.
