1.2.0 release train

Main stays on top. A billing feature merges, main moves one column, release/1.2 is cut from that later commit, a timeout hotfix lands on that branch, v1.2.0 is tagged, and that commit is merged back to main.

THE CUT

Feature first, then release/1.2

Billing merges to main as a two-parent commit. Main then moves one column, and the release branch is cut from that later commit, so the cut does not share ink with the incoming feature merge.

HOTFIX

Timeout fix on the release branch

The hotfix lands on release/1.2, not on a fourth lane. The tagged commit is then merged back to main. Coral marks the hotfix and the tagged release.

TAG

v1.2.0 names the patched cut

The outlined label attaches to the release commit after the hotfix. Main receives that commit through the second merge, one column later.
